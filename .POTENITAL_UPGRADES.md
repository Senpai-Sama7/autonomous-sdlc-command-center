A single monolithic binary cannot achieve 10/10 performance across every domain while preserving zero-dependency local isolation. Attempting to bake AST parsing, enterprise security engines, and multi-repo orchestration natively into the core server violates its primary value proposition: zero supply-chain risk and instant setup.

The optimal architecture is a **Zero-Trust Composable Control Plane**: keep the core Python script as the immutable safety kernel, and plug specialized sidecars, shadow engines, and OS-level primitives around it.

*Caveat: Adding external sidecars (Tree-Sitter, Gitleaks, Container runtimes) forfeits the tool's single biggest asset: its pure-Python standard-library footprint and zero-installation boot time.*

#### 1. Eliminate Two-Pass Latency: Shadow Worktree Engine

* **The Gap:** Waiting for `dry-run` $\rightarrow$ LLM evaluation $\rightarrow$ `confirm` adds substantial round-trip latency to agent execution loops.
* **The Fix:** **Automated Shadow Worktree Branching.**
* Configure the server to spawn a lightweight, isolated Git worktree at `.sdlc/shadow/` on launch.
* Allow the agent auto-confirmation privileges exclusively inside the shadow worktree. Diffs write instantly and execute automated smoke tests in background threads.
* Once tests pass, the main thread performs a single atomic merge/apply to the primary workspace with zero interactive delays.



#### 2. Upgrade String Replacement to AST/Symbolic Refactoring

* **The Gap:** `sdlc_replace_in_file` uses string matching/regex, which breaks on code formatting variances or variable scope renaming.
* **The Fix:** **Dynamic Language Server (LSP) & Tree-Sitter Fallback Hook.**
* Retain Python’s standard-library `ast` module for zero-dependency inspection on `.py` files.
* Add an opportunistic sidecar hook (`shutil.which('tree-sitter')` or local LSP daemon via stdio). When present, route `sdlc_replace_in_file` calls through syntax-tree node identification rather than text matching to guarantee context-aware scope replacement.



#### 3. Deepen Security Scanning: Multi-Tier Entropy Engine

* **The Gap:** Hardcoded regex patterns miss high-entropy tokens, private key formats, or obfuscated secrets.
* **The Fix:** **Shannon Entropy Calculation + Native Scanner Auto-Discovery.**
* Embed a pure-Python Shannon entropy calculator ($H > 4.5$ on string literals) directly into `sdlc_secret_scan` to flag arbitrary unpatterned credentials without external tools.
* Implement an auto-discovery pipeline that checks for native local binaries (`gitleaks`, `trufflehog`). If detected, delegate deep historical Git scanning to the binary and merge results into the unified SARIF payload.



#### 4. Scale to Multi-Repo Enterprise Workspaces

* **The Gap:** Path confinement restricts execution to a single `--path` repository directory.
* **The Fix:** **Context Router & Workspace Manifest.**
* Introduce an `.sdlc/workspace.json` manifest specifying approved relative paths to microservice dependencies.
* Maintain isolated sub-context runtimes per repository while chaining all cryptographic hashes into a single root `.sdlc/audit.jsonl` log using correlated `repo_id` tags.



#### 5. Elevate Filesystem Jail to Kernel-Level Isolation

* **The Gap:** Python path-sanitization rules can theoretically be exposed to OS-level Time-of-Check to Time-of-Use (TOCTOU) symlink races.
* **The Fix:** **Kernel Namespace Enclosure (`bubblewrap` / `sandbox-exec`).**
* Wrap the server launch command in OS-native unprivileged user namespaces (`bwrap` on Linux, `sandbox-exec` on macOS).
* Mount system dependencies as read-only, mount the target workspace as read-write, and strip network capabilities (`--unshare-net`) at the kernel level.

```python
import math
import re
import shutil
import subprocess
import uuid
from collections import Counter
from pathlib import Path
from typing import Dict, List, Optional, Tuple, Any


class EntropySecretScanner:
    """
    Pure-Python Shannon entropy secret detector.
    Calculates H(X) = -\sum P(x_i) \log_2 P(x_i) across extracted candidate tokens.
    Zero external dependencies.
    """

    TOKEN_REGEX = re.compile(r"[A-Za-z0-9+/=_\-\.~]{16,}")

    def __init__(
        self,
        entropy_threshold: float = 4.5,
        min_token_length: int = 16,
        ignored_extensions: Optional[List[str]] = None,
    ):
        self.entropy_threshold = entropy_threshold
        self.min_token_length = min_token_length
        self.ignored_extensions = set(
            ignored_extensions or [".png", ".jpg", ".jpeg", ".lock", ".svg", ".pyc", ".min.js"]
        )

    @staticmethod
    def shannon_entropy(data: str) -> float:
        if not data:
            return 0.0
        length = len(data)
        counts = Counter(data)
        return -sum((count / length) * math.log2(count / length) for count in counts.values())

    def scan_file(self, file_path: Path, root_path: Path) -> List[Dict[str, Any]]:
        if file_path.suffix.lower() in self.ignored_extensions:
            return []

        try:
            content = file_path.read_text(encoding="utf-8", errors="ignore")
        except Exception:
            return []

        findings = []
        rel_path = str(file_path.relative_to(root_path))

        for line_num, line in enumerate(content.splitlines(), start=1):
            for match in self.TOKEN_REGEX.finditer(line):
                token = match.group(0)
                if len(token) < self.min_token_length:
                    continue

                entropy = self.shannon_entropy(token)
                if entropy >= self.entropy_threshold:
                    findings.append(
                        {
                            "file": rel_path,
                            "line": line_num,
                            "token_preview": f"{token[:4]}...{token[-4:]}",
                            "entropy": round(entropy, 3),
                            "length": len(token),
                        }
                    )
        return findings


class ShadowWorktreeEngine:
    """
    Isolated Git worktree engine for zero-latency out-of-band agent execution.
    Applies dry-runs and runs test suites in an ephemeral `.sdlc/shadows/` directory 
    before promoting verified mutations back to the main repository.
    """

    def __init__(self, repo_path: Path):
        self.repo_path = repo_path.resolve()
        self.sdlc_dir = self.repo_path / ".sdlc"
        self.shadow_base = self.sdlc_dir / "shadows"
        self.shadow_base.mkdir(parents=True, exist_ok=True)

    def _run_git(self, args: List[str], cwd: Optional[Path] = None) -> subprocess.CompletedProcess:
        target_dir = str(cwd or self.repo_path)
        return subprocess.run(
            ["git", "-C", target_dir] + args,
            capture_output=True,
            text=True,
            check=False,
        )

    def create_shadow(self) -> Tuple[str, Path]:
        session_id = f"shadow-{uuid.uuid4().hex[:8]}"
        worktree_path = self.shadow_base / session_id
        branch_name = f"sdlc-tmp-{session_id}"

        res = self._run_git(["worktree", "add", "-b", branch_name, str(worktree_path), "HEAD"])
        if res.returncode != 0:
            raise RuntimeError(f"Shadow creation failed: {res.stderr.strip()}")

        return session_id, worktree_path

    def mutate_file(self, worktree_path: Path, relative_path: str, content: str) -> Path:
        target = (worktree_path / relative_path).resolve()
        
        # Enforce path confinement inside shadow jail
        if not str(target).startswith(str(worktree_path.resolve())):
            raise PermissionError(f"Directory traversal blocked: {relative_path}")

        target.parent.mkdir(parents=True, exist_ok=True)
        target.write_text(content, encoding="utf-8")
        return target

    def run_validation(
        self, worktree_path: Path, command: List[str]
    ) -> Tuple[bool, str, str]:
        res = subprocess.run(
            command,
            cwd=str(worktree_path),
            capture_output=True,
            text=True,
            check=False,
        )
        return res.returncode == 0, res.stdout, res.stderr

    def promote_to_main(self, worktree_path: Path, relative_paths: List[str]) -> None:
        for rel in relative_paths:
            src = worktree_path / rel
            dst = self.repo_path / rel

            if not str(dst.resolve()).startswith(str(self.repo_path)):
                raise PermissionError(f"Target write out of bounds: {rel}")

            if src.exists():
                dst.parent.mkdir(parents=True, exist_ok=True)
                shutil.copy2(src, dst)
            elif dst.exists():
                dst.unlink()

    def destroy_shadow(self, session_id: str, worktree_path: Path) -> None:
        branch_name = f"sdlc-tmp-{session_id}"
        self._run_git(["worktree", "remove", "--force", str(worktree_path)])
        self._run_git(["branch", "-D", branch_name])
        
        if worktree_path.exists():
            shutil.rmtree(worktree_path, ignore_errors=True)


# --- Execution Example ---
if __name__ == "__main__":
    repo_root = Path(".").resolve()

    # 1. Entropy Scan
    scanner = EntropySecretScanner(entropy_threshold=4.5)
    sample_file = repo_root / "config.py"
    if sample_file.exists():
        secrets = scanner.scan_file(sample_file, repo_root)
        print("Entropy Findings:", secrets)

    # 2. Shadow Worktree Workflow
    try:
        engine = ShadowWorktreeEngine(repo_root)
        session_id, shadow_path = engine.create_shadow()
        print(f"Created shadow workspace: {shadow_path}")

        # Mutate in shadow
        engine.mutate_file(shadow_path, "src/dummy.py", "print('validated in shadow')\n")

        # Run validation in shadow
        success, stdout, stderr = engine.run_validation(
            shadow_path, ["python", "-m", "py_compile", "src/dummy.py"]
        )
        print(f"Shadow Validation Passed: {success}")

        # Promote if passed
        if success:
            engine.promote_to_main(shadow_path, ["src/dummy.py"])
            print("Promoted changes to main repository.")

    finally:
        if 'session_id' in locals():
            engine.destroy_shadow(session_id, shadow_path)
            print("Shadow workspace destroyed.")
```

### Architectural Design Details

#### 1. Shannon Entropy Secret Scanner

The scanner computes character-frequency entropy $H(X)$ over extracted strings using base-2 logarithm:

$$H(X) = -\sum_{i=1}^{n} P(x_i) \log_2 P(x_i)$$

Standard English text and code syntax average between $2.5$ and $3.8$ bits per character. Randomly generated high-entropy strings (e.g., AWS secret keys, JWTs, private keys) cluster above $4.5$. The regex tokenizes continuous alphanumeric and standard Base64/Hex character sequences before measuring entropy, bypassing false positives from standard whitespace and formatting syntax.

#### 2. Shadow Worktree Engine

The shadow engine wraps `git worktree add -b <ephemeral_branch> <path> HEAD`. It allows an agent to instantly perform full writes, file creations, and integration test executions in a isolated environment without polluting the user's primary working tree or triggering unnecessary UI confirmation gates.

> **Caveat:** Uncommitted changes present in the main working directory during shadow creation will not be present in the shadow worktree unless explicitly stashed and applied during initial worktree setup.
